# Xマッチ射程マッチ調査メモ

確認日: 2026-06-09

## 今日確認できたこと

現在のXマッチは、以前のような固定の射程グループだけで分ける方式ではなく、ブキごとの `matching_range` の値が近い相手を探す方式になっている、という整理が有力。

そのため、アプリに入れるなら `xMatchGroup` のような固定グループ名だけでなく、`matchingRange` を主データとして扱う方がよさそう。

## 主要リソース

### Splatoon3 攻略＆検証 Wiki - Xマッチ

- URL: https://wikiwiki.jp/splatoon3mix/X%E3%83%9E%E3%83%83%E3%83%81
- 確認ポイント:
  - 「11.1.0以降」セクションで、ブキのグループ分けを基にしたマッチングが廃止されたと整理されている。
  - 従来の箱に入れて分ける方式ではなく、ブキごとの「マッチングレンジ」の値が近いブキから相手を探しているという見方が有力、と書かれている。
  - マッチングレンジ一覧が掲載されている。
  - 例として、トライストリンガー `25.0`、R-PEN/5H `26.0`、スプラチャージャー `26.0`、スプラスコープ `26.5`、リッター4K `31.0`、4Kスコープ `33.0` が並んでおり、「ペンや弓が最長寄りの射程帯に近い」ことを確認できる。

### stat.ink - API Info: Weapons (Splatoon 3)

- URL: https://stat.ink/api-info/weapon3?_lang_=en-US
- 確認ポイント:
  - `X Battle (MR)` 列があり、各ブキの matching range を確認できる。
  - `GET /api/v3/weapon?full=1` の `matching_range` と同じ値として使える。
  - 既存実装で取得済みの `matchingRange` は、この新しい見方の主キー候補になる。

### スプラログ記事

- URL: https://spla3sokuhou.games/%E3%80%90%E6%9C%80%E6%96%B0%E7%89%88%E3%80%91%E3%83%9F%E3%83%A9%E3%83%BC%E3%83%9E%E3%83%83%E3%83%81%E6%94%B9%E3%82%81%E5%B0%84%E7%A8%8B%E3%83%9E%E3%83%83%E3%83%81%E3%81%AE%E4%BB%95%E6%A7%98%E3%81%8C/
- 確認ポイント:
  - 2026-03-20の記事。
  - 「固定グループ分けが無くなって、自分より射程が若干長いやつ、短いやつとマッチングしてる気がする」という観測が載っている。
  - 「リッター-ペン」「ペン-弓」「でも弓とリッターはしない」という例があり、ユーザーの指摘と整合する。
  - 元投稿は X の Laze_spl 氏の投稿とされているが、一次情報として使うには元投稿の直接確認が必要。

## 次回実装時の方針メモ

- `xMatchGroup` は旧来/粗い参考値として残す。
- 現行仕様に沿う表示・フィルタは `matchingRange` を使う。
- UI上のラベル案:
  - `MR 25.0`
  - `射程レンジ 25.0`
  - `近い射程で抽選`
- 固定グループを新たに作る場合は、アプリ独自の便宜的な区切りであり、公式/解析値そのものではないと明記する。
