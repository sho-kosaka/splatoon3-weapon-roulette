# 効果音ファイル

ゲーム内SEなど、手元で利用できる音声ファイルを使いたい場合は、このフォルダに以下の名前で配置してください。

- `roulette-loop.mp3` — ルーレットが回っている間にループ再生される音
- `result-se.mp3` — ブキが決まった瞬間に1回だけ再生される音

注意:
- この配布フォルダにはゲーム内SEそのものは同梱していません。
- 著作権のある音声は、権利と利用範囲を確認したうえで、個人利用・身内利用の範囲で配置してください。
- mp3以外を使いたい場合は、`src/main.js` の `customSoundPaths` を変更してから `npm run build:bundle` を実行してください。
- 音声ファイルが未配置、または再生できない場合は、ブラウザ内で生成する代替のカチカチ音・決定音が鳴ります。
